# IronBro Website

A responsive, static landing page and download portal concept for IronBro.

## Run locally

No build step is required.

- Open `index.html` directly in a browser, or
- From this folder run `python -m http.server 8000` and visit `http://localhost:8000`.

## Deploy to Vercel

This is a static website. Import the repository into Vercel and use the project root as the deployment root. No build command or output directory is required for a static HTML deployment.

## Before publishing

1. Replace the placeholder download states with real Android APK and Windows installer URLs.
2. Add actual app screenshots in place of the illustrative CSS phone mockup.
3. Confirm the final feature list and product claims.
4. Add a real privacy policy and terms of service before collecting user data or publishing.
5. Consider moving fonts and imagery to locally hosted assets for more predictable loading and privacy.

## Design and implementation notes

- The page is built with semantic HTML, CSS, and vanilla JavaScript.
- The visual direction is an original dark industrial / lime-accented IronBro identity, informed by the editorial layout and scrolling storytelling of the United Carriers reference.
- Remote Unsplash images and Google Fonts are used for the visual prototype. Internet access is required for those assets.
- Download buttons are intentionally disabled until official release files exist.
- The app screen and workout charts are illustrative concepts, not real application screenshots or live user data.
- Product statements about offline use and future synchronization describe the planned product direction.
